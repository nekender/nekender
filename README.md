### About me

- 🚀 **Co-founder & CTO of Othor AI** (2024–2026): an AI analyst that runs on a company's live data and explains, in plain English, what changed and why. I joined as founding engineer when it was an idea and built the platform end to end.
- 🏢 Took it into **5 enterprise pilots**, including 2 NSE-listed companies. **Nasscom GenAI Foundry Top 40**, **NVIDIA Inception**.
- 🧠 Built **15+ AI agents across 7 LLM providers**, an analytics agent that writes SQL across 21 dialects and fixes its own errors, and the checks that stopped the model from ever showing a client a made-up number.
- 🎯 My rule for AI systems: **the model proposes, code decides.** Every LLM output is validated, every agent action is bounded, and every claim carries its evidence.

### Featured projects

| Project | What it does | Built with |
|---|---|---|
| 🧭 **[blast-radius-agent](https://github.com/nekender/blast-radius-agent)** | Given a pull request, predicts what it can break: the controls, user journeys, tests and requirements at risk, and how sure it is. Crawl, spec, tests and code joined in one graph, with two bounded LLM agents and evals that require every run to be correct. | Python · Playwright · Neo4j · LangGraph · Claude · React |
| 🎙️ **[asha-voice-agent](https://github.com/nekender/asha-voice-agent)** | A voice + chat agent that completes a job application in one session. Speech-to-speech on the call, documents in chat, server-side validation (Aadhaar checksum, IFSC), an event log both channels share, and a transactional outbox. **p50 voice latency 1.8 s, about $0.06 a session.** | Python · FastAPI · WebSockets · Gemini Live · Postgres · React |
| 🧾 **[invoice-posting-agent](https://github.com/nekender/invoice-posting-agent)** | A CLI agent that posts vendor invoices with a person approving every post. Hand-written agent loop, switch between Claude and OpenAI mid-conversation, crash recovery, and a 72-run eval suite that caught a real prompt bug. | Python · Anthropic · OpenAI · SQLite |
| 🛠️ **[errand-agent](https://github.com/nekender/errand-agent)** | A chat agent that books home-service errands. Asks only for missing details, compares providers, and needs explicit approval, enforced in code, before any booking. Recovers from timeouts, crashes and prompt injection. | Python · LLM tool calling · evals |
| 📄 **[Chat-PDF](https://github.com/nekender/Chat-PDF)** | Ask questions about a PDF with a local LLM; every answer highlights the passage it came from. | Python · Mistral 7B · embeddings · Streamlit |
